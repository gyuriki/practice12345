# 낱말 노트

브라우저에서 바로 여는 영어 단어 학습 페이지입니다. 설치나 서버가 필요 없습니다.

`english-words.html`을 더블클릭하면 열립니다.

## 학습 방법

- **플래시카드**: 영어 단어를 보고 뜻을 떠올린 뒤 카드를 뒤집습니다.
- **퀴즈**: 영어를 보고 뜻을 고르거나, 뜻을 보고 영어를 고릅니다.
- **철자**: 한국어 뜻을 보고 영어 철자를 입력합니다. 발음을 들을 수 있습니다.
- **단어 목록**: 영어와 뜻으로 단어를 찾습니다.

주제는 일상, 학교, 감정, 여행, 일, 핵심입니다. 난이도는 초급과 중급입니다. 단어는 48개입니다.

같은 단어를 세 번 맞히면 익힌 단어로 기록됩니다. 오늘 학습 목표는 10개이고, 연속으로 학습한 날도 표시됩니다. 이 기록은 지금 쓰는 브라우저에만 저장됩니다.

## 단축키

플래시카드에서 입력창이 아닐 때 사용할 수 있습니다.

| 키 | 동작 |
| --- | --- |
| 스페이스 | 카드 뒤집기 |
| 1 | 아직 몰라요 |
| 2 | 알아요 |
| → | 건너뛰기 |
| S | 발음 |

퀴즈에서는 `1`–`4`로 보기를 고릅니다. 철자는 Enter로 확인합니다.

## 단어 추가

`english-words.html` 안의 `WORDS` 배열에 객체를 추가합니다. `id`는 서로 달라야 합니다.

```js
{
  id: "borrow",
  en: "borrow",
  ko: "빌리다",
  pos: "v",
  topic: "daily",
  level: "basic",
  example: "Can I borrow your pen?",
  exampleKo: "펜 좀 빌려도 될까?"
}
```

- `pos`: `n` 명사, `v` 동사, `adj` 형용사, `adv` 부사
- `topic`: `daily`, `school`, `emotion`, `travel`, `work`, `core`
- `level`: `basic` 초급, `mid` 중급
- 영국식 철자도 정답으로 받으려면 `also: ["neighbour"]`처럼 넣습니다.
